# hello-character-play

Talk to Socrates in his own world.

A website where Socrates, at 70, in the Athenian agora in the days before his trial, questions you exactly as the Socrates of Plato's dialogues would. The only thing you can do is speak to him. The conversation never has to end.

## Roadmap

1. **Chat** — text conversation with Socrates' mind, live transcript.
2. **Voice** — speak and hear him.
3. **Simple world** — Socrates present in a simple scene that reacts to the conversation.
4. **Detailed world** — the same scene, upgraded to cinematic detail.
5. **Any language** — Socrates replies in the language the visitor chooses.
